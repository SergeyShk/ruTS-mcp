# Статистики русского текста

Инструменты MCP-сервера [ruTS-mcp](https://sergeyshk.github.io/ruTS-mcp/) считают статистики библиотеки ruTS. Каждое значение приходит с описанием, прочтением по шкале, если она есть, и предупреждениями, когда значение неустойчиво. Выводы о тексте делай по этим значениям, а не на глаз.

## Подключение

Инструменты сервера - `analyze_text`, `kwic`, `collocations`, `dispersion`, `keyness`, `compare_texts` (в Claude Code - `mcp__ruts__analyze_text` и так далее, из плагина `ruts` - `mcp__plugin_ruts_ruts__analyze_text`). Если их нет, не подменяй измерения оценкой на глаз: предложи пользователю подключить сервер. Нужен [uv](https://docs.astral.sh/uv/getting-started/installation/), который сам скачает пакет и Python.

- Плагин `ruts` подключает сервер сам в Claude Code и в Cowork на компьютере пользователя. В чате claude.ai и Claude Desktop сервер из плагина не запускается: в Claude Desktop его подключают вручную, как ниже. Если в Claude Code инструментов нет и при плагине, скорее всего, не установлен uv.
- Claude Code без плагина: `claude mcp add ruts -- uvx ruts-mcp` - для текущего проекта, `claude mcp add --scope user ruts -- uvx ruts-mcp` - для всех проектов; затем начать новую сессию.
- Claude Desktop, Cursor и другие клиенты: запись `"ruts": {"command": "uvx", "args": ["ruts-mcp"]}` в `mcpServers` конфигурации клиента.

Группам `lexical`, `verse`, `syntax` и `keyness` без эталона нужны словари и модель spaCy, их скачивает команда `uvx ruts-mcp download`. Если предупреждение в ответе говорит, что словарь или модель не скачаны, предложи эту команду. Что уже скачано, показывает ресурс `ruts://data`. Подробнее - в [документации](https://sergeyshk.github.io/ruTS-mcp/installation/).

## Какой инструмент вызывать

| Задача | Вызов |
| :----- | :---- |
| Для какого возраста и класса текст, насколько он труден | `analyze_text`, группы `basic`, `readability`, `syntax` |
| Канцелярит, бюрократический стиль | `analyze_text`, группы `style`, `syntax`; примеры в контексте - `kwic` |
| SEO-метрики текста для сайта | `analyze_text`, группа `style`; ключевые слова - `keyness` |
| Метр, рифма, окончания строк, звукопись стихотворения | `analyze_text`, группы `verse`, `phon` |
| Лексическое разнообразие, морфология, связность, частотность лексики | `analyze_text`, группы `diversity`, `morph`, `cohesion`, `lexical` |
| Ключевые слова относительно языка или другого текста | `keyness`; эталон - `reference` или `reference_path`, без них - частотный словарь |
| Как употребляется слово, цитаты с контекстом | `kwic`; `by_lemma` - все формы слова |
| Устойчивые сочетания, сочетаемость слова | `collocations`; `node` - сочетаемость одного слова |
| Проходит ли слово через весь текст или сосредоточено в одном месте | `dispersion` |
| Чем различаются два текста или корпуса, авторство, текст человека или модели | `compare_texts`, затем `keyness` с другим текстом как эталоном |

## Как вызывать

- Текст из файла передавай абсолютным путем: `path`, у `keyness` еще `reference_path`, у `compare_texts` - `a_paths` и `b_paths`. Не пересылай содержимое файла в аргументе.
- Запрашивай только нужные группы: каждая группа - ключ ответа, лишние раздувают его.
- В повторных вызовах `analyze_text` передавай `descriptions: false`: описания уже известны по первому ответу.
- `readability_preset` оставляй `plainrussian`; `fiction` и `academic` - только когда пользователь просит именно их.

## Как читать ответ

- Сначала прочитай `warnings`: короткий текст, текст не на русском языке, не скачанные словари или модель. Не делай выводов по значениям, которые предупреждения ставят под сомнение, и скажи об этом пользователю.
- У статистики - значение `value`, доля `share` или прочтение `interpretation` и описание `description`; `null` - статистика на этом тексте не определена.
- Отвечай прочтением, а не голыми числами: класс и возраст читателя, полоса шкалы, норма сервиса. Шкалы удобочитаемости - в ресурсе `ruts://scales/readability`, нормы стиля - в `ruts://scales/style`.
- Нормы SEO-метрик рассчитаны на тексты сайтов в несколько сотен слов, к художественной прозе они неприменимы.
- Выбирай статистики, которые отвечают на вопрос пользователя, и не пересказывай весь ответ.
- Подкрепляй выводы цитатами из текста: найденные слова маркеров канцелярита - в `found`, контекст слова дает `kwic`.

## Разборы

Те же разборы есть промптами сервера `readability_review`, `officialese_review`, `verse_review`, `seo_review` и `compare_review`, их вызывает пользователь (в Claude Code - из меню `/`, например `/mcp__ruts__readability_review`).

### Удобочитаемость

1. `analyze_text` с группами `basic`, `readability`, `syntax`.
2. По сводному классу и его прочтению назови ступень обучения и возраст читателя. Если формулы класса заметно расходятся, скажи об этом.
3. Объясни, что делает текст трудным: длина предложений, длинные и сложные слова, длина зависимостей и глубина дерева, придаточные и обороты.
4. Предложи конкретные правки с цитатами: какие предложения разбить, какие слова заменить.

### Канцелярит

1. `analyze_text` с группами `style` и `syntax`.
2. Оцени маркеры: отглагольные существительные, производные предлоги, вводные слова и штампы (`style`, с найденными словами в `found`), расщепленные сказуемые, цепочки родительных падежей, пассив и отношение существительных к глаголам (`syntax`, конструкции найди в тексте сам).
3. Все вхождения слова в контексте покажет `kwic`.
4. Для каждого примера предложи живую замену: «оказать помощь» - «помочь», «в целях повышения» - «чтобы повысить».

### Стихотворение

1. `analyze_text` с группами `verse` и `phon`. Знак ударения в тексте (замо́к) важнее словаря.
2. Назови метр и число стоп, оцени отклонения от метра и пропуски ударений. Если метр не определен, предположи, что это за стих: дольник, акцентный стих, верлибр.
3. Опиши рифмовку по схемам строф и окончания строк: мужские, женские, дактилические.
4. Оцени звукопись по индексам аллитерации и ассонанса и приведи строки, где она слышна.

### SEO-проверка

1. `analyze_text` с группой `style` и `keyness` без `reference`: эталоном станет частотный словарь русского языка.
2. Сравни тошноту, водность, заспамленность и естественность по Ципфу с нормами сервисов.
3. По ключевым словам скажи, о чем текст для поисковой системы, а по самым частым значимым словам (`nausea_words` группы `style`) - какие слова повторяются слишком часто.
4. Предложи правки: что сократить, какие повторы заменить синонимами.

### Сравнение двух текстов

1. `compare_texts` с `a` = [текст A] и `b` = [текст B]: размер окна подбирается по длине текстов. Если окон меньше двух (в тексте меньше 200 слов), сравни результаты `analyze_text` для обоих текстов.
2. `keyness` с текстом A и `reference` = текст B, затем с `positive: false`: это слова, которые в A чаще и реже, чем в B.
3. По одному тексту на корпус различия могут быть особенностями текста, а не автора или жанра.
4. Опиши главные различия по признакам с наибольшей по модулю дельтой Клиффа и по ключевым словам, с цитатами из обоих текстов.
