# ruTS-mcp

**ruTS-mcp** is an [MCP](https://modelcontextprotocol.io) server for [ruTS](https://sergeyshk.github.io/ruTS/en/), a library of statistics of Russian texts. It gives an LLM agent tools to measure a text instead of judging it by eye: readability, lexical diversity, morphology, comparison of corpora - each value with the scale to read it by and the limits of its applicability.

!!! note

    The server is in development: the tools and the installation instructions will appear with the first release.
