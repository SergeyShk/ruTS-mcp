# ruTS-mcp

![ruTS-mcp](img/ruts-mcp.svg)

**ruTS-mcp** - [MCP](https://modelcontextprotocol.io)-сервер для [ruTS](https://sergeyshk.github.io/ruTS/), библиотеки статистик русского текста. Он дает LLM-агенту инструменты, чтобы измерить текст, а не оценивать его на глаз: удобочитаемость, лексическое разнообразие, морфологию, синтаксис, стих, сравнение корпусов - каждое значение вместе со шкалой, по которой его читать, и границами применимости.

## Возможности { #features }

| Инструмент | Что делает |
| :--------- | :--------- |
| [`analyze_text`](tools.md#analyze_text) | Статистики текста по группам: базовые, удобочитаемость, лексическое разнообразие, морфология, фоностатистики, связность, стиль и канцелярит, лексическая сложность, стих, синтаксис |
| [`kwic`](tools.md#kwic) | Все вхождения слова или словосочетания с контекстом |
| [`collocations`](tools.md#collocations) | Устойчивые сочетания и сочетаемость слова |
| [`dispersion`](tools.md#dispersion) | Насколько равномерно слова распределены по тексту |
| [`keyness`](tools.md#keyness) | Ключевые слова текста относительно русского языка или другого текста |
| [`compare_texts`](tools.md#compare_texts) | Чем различаются два корпуса текстов по признакам стиля |

Кроме инструментов, сервер отдает [ресурсы](resources.md#resources) - шкалы удобочитаемости, нормы стиля, состояние словарей - и [промпты](resources.md#prompts) типовых разборов: удобочитаемость, канцелярит, стихотворение, SEO-проверка, сравнение двух текстов.

## Пример { #example }

На вопрос «для какого читателя написан этот текст?» агент вызывает `analyze_text` с группой `readability` и получает не только числа, но и их прочтение и оговорки:

```json
{
  "readability": {
    "consensus_grade": {
      "value": 25.5,
      "interpretation": "аспирантура (старше 22 лет)",
      "description": "Сводный класс: медиана формул класса и индекса Флеша, переведенного в класс; число лет обучения, нужное для понимания текста"
    },
    "flesch_reading_easy": {
      "value": -39.95,
      "interpretation": "выпускник университета",
      "description": "Индекс Флеша: номинально от 0 до 100, чем выше, тем легче текст; прочтение по шкале Флеша"
    }
  },
  "warnings": [
    "Предложений в тексте: 1, меньше 30. Формулы удобочитаемости опираются на среднюю длину предложения, исходный SMOG - на выборку из 30 предложений: на коротком тексте значения неустойчивы, включая сводный класс, это грубая оценка"
  ]
}
```

Это одно предложение канцелярита: «В целях повышения качества обслуживания клиентов в кратчайшие сроки осуществляется проведение мероприятий по модернизации оборудования, предусмотренных утвержденным планом развития организации на текущий период.»

## Быстрый старт { #quickstart }

Подключение к Claude Code и загрузка словарей и модели spaCy для групп `lexical`, `verse` и `syntax`:

```bash
claude mcp add ruts -- uvx ruts-mcp
uvx ruts-mcp download
```

Подключение к Claude Desktop, Cursor и другим клиентам и настройки сервера - на странице [Установка](installation.md).
