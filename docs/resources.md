# Ресурсы и промпты

## Ресурсы { #resources }

Ресурсы - справочные данные, которые клиент может приложить к разговору. Все они в Markdown и собираются из данных ruTS при чтении.

| URI | Что внутри |
| :-- | :--------- |
| `ruts://scales/readability` | Класс и возраст читателя для формул класса, полосы индекса Флеша и LIX, классы RIX |
| `ruts://scales/style` | Нормы SEO-сервисов для тошноты, водности, заспамленности и естественности по Ципфу |
| `ruts://data` | Каталог данных и что из словарей и модели spaCy скачано |

В Claude Code ресурс подключается упоминанием, например `@ruts:ruts://scales/readability`.

## Промпты { #prompts }

Промпты - готовые сценарии разбора: какие инструменты вызвать, как читать результат и чем закончить.

| Промпт | Аргументы | Что делает |
| :----- | :-------- | :--------- |
| `readability_review` | `text` | Для какого читателя написан текст и как его упростить |
| `officialese_review` | `text` | Канцелярит в тексте и живые замены |
| `verse_review` | `text` | Метр, рифмовка, окончания строк и звукопись стихотворения |
| `seo_review` | `text` | Нормы SEO-сервисов и ключевые слова текста для сайта |
| `compare_review` | `text_a`, `text_b` | Чем различаются два текста по стилю и лексике |

В Claude Code промпт вызывается командой `/mcp__ruts__<имя>`, например `/mcp__ruts__readability_review`. Claude Code делит аргументы команды по пробелам, и кавычки не помогают: в аргумент `text` попадает только первое слово. Поэтому свой текст в Claude Code удобнее разобрать обычной просьбой, например «оцени удобочитаемость этого текста через ruts» с текстом ниже. Другие клиенты показывают промпты MCP по-своему.
