# Инструменты

## Общее { #common }

Все инструменты только читают переданный текст: ничего не сохраняют и не ходят в сеть. Текст и корпус ограничены по длине (`RUTS_MCP_MAX_TEXT_LENGTH`, по умолчанию 500 000 символов, см. [Настройки](installation.md#settings)).

В каждом ответе есть ключ `warnings` - причины, по которым значения могут быть неустойчивы или не иметь смысла для этого текста: короткий текст, текст не на русском языке, не скачанные словари или модель, статистика, не определенная на тексте. Агенту стоит читать их до выводов. Числа округляются до четырех значащих цифр, неопределенное значение отдается как `null`.

Определения и формулы метрик - в [документации ruTS](https://sergeyshk.github.io/ruTS/); сервер передает значения ruTS как есть.

## analyze_text { #analyze_text }

Статистики текста по группам; считаются только запрошенные группы.

| Параметр | По умолчанию | Описание |
| :------- | :----------: | :------- |
| `text` | - | Текст на русском языке |
| `groups` | `["basic", "readability"]` | Группы статистик; каждая - ключ результата |
| `distributions` | `false` | Добавить распределения слов по числу букв и слогов и знаков препинания по типам (группа `basic`) |
| `readability_preset` | `plainrussian` | Коэффициенты формул удобочитаемости: `plainrussian` - тексты общего назначения, `fiction` - художественные, `academic` - учебные |

| Группа | Что считает | Данные |
| :----- | :---------- | :----: |
| `basic` | Предложения, слова, слоги, символы, длинные и сложные слова ([BasicStats](https://sergeyshk.github.io/ruTS/stats/basic_stats/)) | - |
| `readability` | Сводный класс и формулы удобочитаемости с классом школы и возрастом читателя, время чтения ([ReadabilityStats](https://sergeyshk.github.io/ruTS/stats/readability_stats/)) | - |
| `diversity` | Лексическое разнообразие: TTR и поправки к нему, MATTR, MTLD, HD-D, законы Ципфа и Хипса ([DiversityStats](https://sergeyshk.github.io/ruTS/stats/diversity_stats/)) | - |
| `morph` | Части речи, грамматические признаки, формы глагола ([MorphStats](https://sergeyshk.github.io/ruTS/stats/morph_stats/)) | - |
| `phon` | Классы звуков, сочетания согласных, аллитерация и ассонанс ([PhonStats](https://sergeyshk.github.io/ruTS/stats/phon_stats/)) | - |
| `cohesion` | Связность: повторы между предложениями, данность, коннекторы ([CohesionStats](https://sergeyshk.github.io/ruTS/stats/cohesion_stats/)) | - |
| `style` | Тошнота, водность, заспамленность с прочтением по нормам SEO-сервисов, маркеры канцелярита ([StyleStats](https://sergeyshk.github.io/ruTS/stats/style_stats/)) | - |
| `lexical` | Частотность слов, частотные полосы, сюрпризал, лексическая плотность ([LexicalStats](https://sergeyshk.github.io/ruTS/stats/lexical_stats/)) | частотный словарь |
| `verse` | Метр, число стоп, рифмовка, окончания строк ([VerseStats](https://sergeyshk.github.io/ruTS/stats/verse_stats/)) | словарь ударений |
| `syntax` | Длины зависимостей, глубина дерева, клаузы, обороты, пассив, расщепленные сказуемые ([SyntaxStats](https://sergeyshk.github.io/ruTS/stats/syntax_stats/)) | модель spaCy |

Как скачать данные - в разделе [Словари и модель spaCy](installation.md#data).

Каждая статистика в ответе - объект с полями:

| Поле | Описание |
| :--- | :------- |
| `value` | Значение |
| `share` | Доля от всех слов или символов, если она есть |
| `interpretation` | Прочтение по шкале или норме ruTS, если шкала есть: класс и возраст читателя, полоса индекса Флеша, норма Text.ru |
| `description` | Что считает статистика |

Шкалы прочтения отдают [ресурсы](resources.md#resources) `ruts://scales/readability` и `ruts://scales/style`.

## kwic { #kwic }

Все вхождения слова или словосочетания с контекстом слева и справа - конкорданс, по которому агент цитирует текст.

| Параметр | По умолчанию | Описание |
| :------- | :----------: | :------- |
| `text` | - | Текст |
| `keyword` | - | Слово или словосочетание |
| `window` | `5` | Число слов контекста с каждой стороны, до 50 |
| `by_lemma` | `false` | Искать все формы слова: «кот» находит «кота» и «коты» |
| `limit` | `50` | Наибольшее число строк ответа, до 500 |

Ответ - число вхождений `n_matches` и строки `matches` с полями `left`, `keyword` и `right`.

## collocations { #collocations }

Коллокации - пары слов, которые встречаются вместе чаще, чем случайно: устойчивые сочетания, термины, сочетаемость слова.

| Параметр | По умолчанию | Описание |
| :------- | :----------: | :------- |
| `text` | - | Текст |
| `window` | `5` | Наибольшее расстояние между словами пары, от 1 до 10 |
| `measure` | `logdice` | Мера ассоциации: `logdice`, `mi`, `mi3`, `t_score`, `dice`, `log_likelihood`, `npmi`, `min_sensitivity` |
| `min_freq` | `2` | Наименьшая частота пары |
| `node` | - | Слово, сочетаемость которого нужна; не задано - все пары |
| `lemmatize` | `true` | Сравнивать леммы: «точка зрения» и «точки зрения» - одна пара |
| `top_n` | `20` | Число пар в ответе, до 200 |

Ответ - пары по убыванию меры с частотами слов и пары и строка `measure`, которая говорит, как читать значения меры.

## dispersion { #dispersion }

Дисперсия - насколько равномерно слово распределено по тексту: отличает слово, которое проходит через весь текст, от слова, сосредоточенного в одном месте. Текст делится на равные части, для каждого слова считаются меры Гриса; основная из них - DP, от 0 (равномерно) почти до 1 (в одной части).

| Параметр | По умолчанию | Описание |
| :------- | :----------: | :------- |
| `text` | - | Текст |
| `words` | - | Слова, дисперсия которых нужна, до 200; не задано - самые частые слова |
| `parts` | `10` | Число частей текста, от 2 до 100 |
| `lemmatize` | `true` | Сравнивать леммы |
| `top_n` | `20` | Число самых частых слов, если `words` не задано |

## keyness { #keyness }

Ключевые слова - слова, которые в тексте значимо чаще (или реже), чем в эталоне. Эталон по умолчанию - частотный словарь современного русского языка (его скачивает `ruts-mcp download`), так что ответ показывает, чем лексика текста отличается от обычного языка; эталоном может быть и другой текст.

| Параметр | По умолчанию | Описание |
| :------- | :----------: | :------- |
| `text` | - | Текст |
| `reference` | - | Текст-эталон; не задано - частотный словарь |
| `measure` | `log_likelihood` | Мера сортировки: `log_likelihood`, `log_ratio`, `chi2`, `diff`, `bic`, `ell`, `odds_ratio` |
| `positive` | `true` | Слова, которые чаще в тексте; `false` - которые чаще в эталоне |
| `min_freq` | `2` | Наименьшая частота слова там, где оно чаще |
| `lemmatize` | `true` | Сравнивать леммы; со словарем леммы сравниваются всегда |
| `top_n` | `20` | Число слов в ответе, до 200 |

Для каждого слова ответ дает частоты в тексте и эталоне, логарифм правдоподобия G² с p-значением и Log Ratio - во сколько раз слово чаще. Со словарем имена, термины и опечатки, которых в нем нет, попадают в ключевые слова.

## compare_texts { #compare_texts }

Сравнение двух корпусов по признакам стиля - для атрибуции авторства, сравнения жанров и переводов, текстов человека и модели. Тексты режутся на окна равной длины, у каждого окна считаются около 110 признаков ruTS, и распределения каждого признака в корпусах сравниваются.

| Параметр | По умолчанию | Описание |
| :------- | :----------: | :------- |
| `a` | - | Тексты первого корпуса |
| `b` | - | Тексты второго корпуса |
| `window` | `1000` | Размер окна в словах, от 100 до 10 000; `null` - тексты целиком |
| `top_n` | `15` | Число признаков с наибольшим различием, до 200 |

Ответ - признаки по убыванию различия: средние по окнам, разность медиан с 95% доверительным интервалом, дельта Клиффа (по модулю от 0,147 - малый, от 0,33 - средний, от 0,474 - большой эффект) и p-значение с поправкой Холма. В каждом корпусе нужно хотя бы по два окна; надежнее, когда в корпусах по нескольку текстов: окна одного текста не независимы.
