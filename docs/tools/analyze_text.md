# Статистики текста

``` {.python .signature}
analyze_text(text="", path=null, groups=["basic", "readability"], distributions=false, readability_preset="plainrussian", descriptions=true)
```

Измеряет текст статистиками ruTS по группам: считаются только запрошенные группы, и каждая становится ключом ответа. Статистика приходит со значением, долей или прочтением по шкале, если они есть, и с описанием того, что она считает. Ключ `warnings` говорит, когда значения неустойчивы или не имеют смысла для этого текста. Описания, известные по прошлому вызову, можно не запрашивать: `descriptions=false` дает ответ короче.

Ошибки - [общие для инструментов](index.md#errors) и текст без слов.

=== "Вызов"

    ``` json
    {
      "name": "analyze_text",
      "arguments": {
        "text": "В целях повышения качества обслуживания клиентов в кратчайшие сроки осуществляется проведение мероприятий по модернизации оборудования, предусмотренных утвержденным планом развития организации на текущий период.",
        "groups": ["style"],
        "descriptions": false
      }
    }
    ```

## Параметры

| Параметр | Тип | По умолчанию | Описание |
| :------- | :-- | :----------- | :------- |
| `text` | `string` | `""` | Текст на русском языке |
| `path` | `string` | `null` | Абсолютный путь к файлу с текстом вместо `text` |
| `groups` | `array[string]` | `["basic", "readability"]` | [Группы](#groups) статистик; каждая - ключ ответа |
| `distributions` | `boolean` | `false` | Добавить распределения слов по числу букв и слогов и знаков препинания по типам (группа `basic`) |
| `readability_preset` | `string` | `"plainrussian"` | Коэффициенты теста Флеша-Кинкайда (у `academic` - и индекса Флеша), от них зависит и сводный класс: `plainrussian` откалиброван по школьным классам и подходит для любых текстов; `fiction` - коэффициенты Оборневой по художественным текстам, дает класс на несколько лет выше; `academic` - коэффициенты Соловьёва, Иванова и Солнышкиной по учебникам 5-11 классов |
| `descriptions` | `boolean` | `true` | Добавить к статистикам описания |

## Группы { #groups }

| Группа | Что считает | Данные |
| :----- | :---------- | :----- |
| [`basic`](#basic) | Предложения, слова, слоги, символы, длинные и сложные слова | - |
| [`readability`](#readability) | Сводный класс и формулы удобочитаемости с классом школы и возрастом читателя | - |
| [`diversity`](#diversity) | Лексическое разнообразие | - |
| [`morph`](#morph) | Части речи, грамматические признаки, формы глагола | - |
| [`phon`](#phon) | Классы звуков, сочетания согласных, аллитерация и ассонанс | - |
| [`cohesion`](#cohesion) | Связность: повторы между предложениями, данность, коннекторы | - |
| [`style`](#style) | SEO-метрики с нормами сервисов и маркеры канцелярита | - |
| [`lexical`](#lexical) | Частотность слов, частотные полосы, сюрпризал | частотный словарь |
| [`verse`](#verse) | Метр, рифмовка, окончания строк | словарь ударений |
| [`syntax`](#syntax) | Синтаксис по дереву зависимостей | модель spaCy |

Как скачать данные - в разделе [Словари и модель spaCy](../installation.md#data). Без данных группа не падает: метрики, которым они нужны, не считаются, а предупреждение называет команду, которая их скачивает.

### Базовые статистики { #basic }

`basic` · [BasicStats](https://sergeyshk.github.io/ruTS/stats/basic_stats/)
{ .metric-meta }

Предложения, слова, слоги, символы, буквы, пробелы и знаки препинания; уникальные, длинные (от 6 букв), сложные (от 4 слогов), простые, односложные и многосложные слова. Счетчик слов или символов идет с долей от всех слов или символов (`share`). С `distributions=true` группа добавляет распределения слов по числу букв и слогов и знаков препинания по типам.

</div>

<div class="metric-card" markdown>

### Удобочитаемость { #readability }

`readability` · [ReadabilityStats](https://sergeyshk.github.io/ruTS/stats/readability_stats/) · [`ruts://scales/readability`](../resources.md#resources)
{ .metric-meta }

Сводный класс и формулы Флеша-Кинкайда, Флеша, Колман-Лиау, SMOG, ARI, LIX, RIX, Соловьёва-Иванова-Солнышкиной, Мацковского, Дейла-Чейла и Ганнинга, время чтения. Формулы класса и сводный класс читаются классом школы и возрастом читателя, индекс Флеша, LIX и RIX - полосой своей шкалы; у формулы Мацковского и времени чтения шкалы нет. Коэффициенты теста Флеша-Кинкайда и индекса Флеша задает `readability_preset`, остальные формулы от него не зависят. На тексте короче 30 предложений формулы неустойчивы, и ответ об этом предупреждает.

</div>

<div class="metric-card" markdown>

### Лексическое разнообразие { #diversity }

`diversity` · [DiversityStats](https://sergeyshk.github.io/ruTS/stats/diversity_stats/)
{ .metric-meta }

TTR и поправки к нему, MATTR, MSTTR, MTLD, HD-D, индексы Симпсона, Юла и Оноре, энтропия, законы Ципфа и Хипса. На тексте короче 50 слов меры неустойчивы, а на тексте короче 200 слов тексты стоит сравнивать по MATTR, MTLD и HD-D: ответ об этом предупреждает.

</div>

<div class="metric-card" markdown>

### Морфология { #morph }

`morph` · [MorphStats](https://sergeyshk.github.io/ruTS/stats/morph_stats/)
{ .metric-meta }

Части речи и грамматические признаки по pymorphy3 без снятия омонимии и доли форм глагола: наклонения, инфинитив, причастия, деепричастия, совершенный вид, страдательные и возвратные формы. Значение признака - число слов с каждым его значением, с подписями значений из ruTS, а `share` - их доли от всех слов.

</div>

<div class="metric-card" markdown>

### Фоностатистики { #phon }

`phon` · [PhonStats](https://sergeyshk.github.io/ruTS/stats/phon_stats/)
{ .metric-meta }

Доли гласных, сонорных, звонких и глухих согласных, тяжелые сочетания согласных, зияния, жесткость, открытые слоги, индексы аллитерации и ассонанса. Считаются по буквам, без ударения, оглушения и редукции.

</div>

<div class="metric-card" markdown>

### Связность { #cohesion }

`cohesion` · [CohesionStats](https://sergeyshk.github.io/ruTS/stats/cohesion_stats/)
{ .metric-meta }

Связность по образцу Coh-Metrix: повторы существительных, аргументов и знаменательных слов между предложениями, местоимения, данность, повтор времени и вида, коннекторы по классам на 1000 слов. Коннекторы делятся по месту в предложении: межпредложенческие стоят в его начале («Однако», «Поэтому»), остальные - внутрипредложенческие, в том числе подчинительные союзы и предлоги в начале предложения («Когда он пришел»).

</div>

<div class="metric-card" markdown>

### Стиль { #style }

`style` · [StyleStats](https://sergeyshk.github.io/ruTS/stats/style_stats/) · [`ruts://scales/style`](../resources.md#resources)
{ .metric-meta }

SEO-метрики по словоформам - классическая и академическая тошнота, водность, заспамленность и естественность по Ципфу с прочтением по нормам Advego, Text.ru, pr-cy и megaindex - и лексические маркеры канцелярита: отглагольные существительные, производные предлоги, вводные слова, штампы. Нормы рассчитаны на тексты сайтов в несколько сотен слов, к художественной прозе они неприменимы; на тексте короче 200 или длиннее 1000 слов ответ об этом предупреждает.

Сверх метрик ruTS группа отдает число слов `n_words`, самые частые словоформы `top_words` и самые частые значимые слова `nausea_words`, по которым считается академическая тошнота. У маркеров канцелярита - число вхождений `count` и найденные слова и фразы `found`. Синтаксические маркеры канцелярита - в группе [`syntax`](#syntax): для проверки на канцелярит берите обе группы.

</div>

<div class="metric-card" markdown>

### Лексическая сложность { #lexical }

`lexical` · [LexicalStats](https://sergeyshk.github.io/ruTS/stats/lexical_stats/) · частотный словарь
{ .metric-meta }

Доля слов, найденных в частотном словаре Ляшевской и Шарова, средняя частотность (ipm) и ее логарифм, диапазон и дисперсия по корпусу, сюрпризал и перплексия, доли слов из 1000-10000 самых частых лемм, лексическая плотность. Без словаря группа считает только доли частотных полос и лексическую плотность.

</div>

<div class="metric-card" markdown>

### Стих { #verse }

`verse` · [VerseStats](https://sergeyshk.github.io/ruTS/stats/verse_stats/) · словарь ударений
{ .metric-meta }

Строки и строфы, метр и число стоп, отклонения от метра и пропуски ударений, доля рифмованных строк и схемы рифмовки, мужские, женские и дактилические окончания. Знак ударения в тексте («замо́к») важнее словаря.

</div>

<div class="metric-card" markdown>

### Синтаксис { #syntax }

`syntax` · [SyntaxStats](https://sergeyshk.github.io/ruTS/stats/syntax_stats/) · модель spaCy
{ .metric-meta }

Синтаксис по дереву зависимостей модели spaCy: длина зависимостей, глубина и ветвистость дерева, валентность глаголов, клаузы, придаточные и инфинитивные клаузы, сочинительные цепочки, модификаторы существительного, цепочки родительных падежей, причастные и деепричастные обороты, пассив, инфинитивы, отрицания, расщепленные сказуемые («оказать помощь»), отношение существительных к глаголам. Инфинитив при глаголе («хочу спать») - своя клауза, но не придаточная, а модальное или фазовое сочетание («может уйти», «начал читать») - одна клауза. На длинном тексте разбор занимает секунды.

</div>

## Результат { #result }

По ключу на каждую запрошенную группу и `warnings`. Статистика группы - объект с полями:

| Поле | Тип | Описание |
| :--- | :-- | :------- |
| `value` | `number` / `string` / `object` | Значение; `null` - статистика на этом тексте не определена |
| `share` | `number` / `object` | Доля от всех слов или символов, если она есть |
| `interpretation` | `string` | Прочтение по шкале или норме ruTS, если шкала есть: класс и возраст читателя, полоса индекса Флеша, норма Text.ru |
| `count` | `integer` | У маркеров канцелярита группы `style`: число вхождений |
| `found` | `object` | У маркеров канцелярита группы `style`: найденные слова и фразы с частотами, до 20 самых частых |
| `description` | `string` | Что считает статистика; без него при `descriptions=false` |
