# Инструменты

Инструменты сервера измеряют текст статистиками [ruTS](https://sergeyshk.github.io/ruTS/). Все они только читают переданный текст: ничего не сохраняют и не ходят в сеть.

| Инструмент | Что делает | Данные |
| :--------- | :--------- | :----- |
| [`analyze_text`](analyze_text.md) | Статистики текста по десяти группам с прочтением по шкалам | словари и модель spaCy для групп `lexical`, `verse` и `syntax` |
| [`kwic`](kwic.md) | Все вхождения слова или словосочетания с контекстом | - |
| [`collocations`](collocations.md) | Пары слов, которые встречаются вместе чаще, чем случайно | - |
| [`dispersion`](dispersion.md) | Насколько равномерно слова распределены по тексту | - |
| [`keyness`](keyness.md) | Ключевые слова относительно русского языка или другого текста | частотный словарь, если эталон не задан |
| [`compare_texts`](compare_texts.md) | Чем различаются два корпуса текстов по признакам стиля | - |

Как скачать данные - в разделе [Словари и модель spaCy](../installation.md#data). Определения и формулы метрик - в документации ruTS: сервер передает значения ruTS как есть.

## Текст { #text }

Текст передается аргументом `text` или путем к файлу `path` - абсолютным путем к файлу в UTF-8 на машине, где запущен сервер. Файл удобнее для длинного текста: агенту не нужно пересылать его в аргументе, и статистики считаются по исходному тексту, а не по его пересказу. Текст и корпус ограничены по длине: `RUTS_MCP_MAX_TEXT_LENGTH`, по умолчанию 500 000 символов (см. [Настройки](../installation.md#settings)).

Знаки ударения и мягкие переносы внутри слов не мешают анализу: слова сравниваются без них, `kwic` показывает текст как написан, а группа `verse` берет из знака ударение. `analyze_text`, как ruTS, считает «ещё» и «еще» разными словами, а `kwic`, `collocations`, `dispersion` и `keyness` сводят ё к е.

## Ответ { #response }

В каждом ответе есть ключ `warnings` - причины, по которым значения могут быть неустойчивы или не иметь смысла для этого текста: короткий текст, текст не на русском языке, не скачанные словари или модель, статистика, не определенная на тексте. Агенту стоит читать их до выводов. Числа округляются до четырех значащих цифр, неопределенное значение отдается как `null`.

## Ошибки { #errors }

Ошибка приходит агенту как ошибка инструмента с сообщением о том, что не так с вызовом. Общие для всех инструментов:

- аргумент не проходит схему инструмента: неверный тип, число вне допустимого диапазона, значение не из списка;
- текст не задан или задан вместе с путем к файлу;
- путь не абсолютный, файл не читается, не в кодировке UTF-8 или больше лимита;
- текст длиннее лимита `RUTS_MCP_MAX_TEXT_LENGTH`;
- в тексте одиночные суррогатные символы UTF-16: так бывает, если строку обрезали посреди эмодзи.

Ошибки, которые зависят от инструмента, перечислены на его странице.
