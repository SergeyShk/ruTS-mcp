# Конкорданс KWIC

``` {.python .signature}
kwic(keyword, text="", path=null, window=5, by_lemma=false, limit=50)
```

Все вхождения слова или словосочетания с контекстом слева и справа - конкорданс, по которому агент цитирует текст и видит, как слово употребляется. Слова сравниваются без учета регистра и буквы ё, с `by_lemma` - по леммам: «окно» находит «окне» и «окна». Словосочетание не переходит через конец предложения.

Строки ограничены параметром `limit` и объемом ответа - около 40 000 символов контекста; если показаны не все вхождения, предупреждение говорит, сколько их.

Ошибки - [общие для инструментов](index.md#errors) и ключевое слово без слов.

=== "Вызов"

    ``` json
    {
      "name": "kwic",
      "arguments": {
        "keyword": "окно",
        "text": "Кот сидел на окне и смотрел на птиц. Птицы улетели, и кот уснул на окне. Завтра кот снова будет сидеть на окне и смотреть на птиц.",
        "window": 3,
        "by_lemma": true
      }
    }
    ```

=== "Результат"

    ``` json
    {
      "n_matches": 3,
      "matches": [
        {"left": "Кот сидел на", "keyword": "окне", "right": "и смотрел на"},
        {"left": "кот уснул на", "keyword": "окне", "right": ". Завтра кот снова"},
        {"left": "будет сидеть на", "keyword": "окне", "right": "и смотреть на"}
      ],
      "warnings": []
    }
    ```

## Параметры

| Параметр | Тип | По умолчанию | Описание |
| :------- | :-- | :----------- | :------- |
| `keyword` | `string` | - | Слово или словосочетание |
| `text` | `string` | `""` | Текст |
| `path` | `string` | `null` | Абсолютный путь к файлу с текстом вместо `text` |
| `window` | `integer` | `5` | Число слов контекста с каждой стороны, до 50 |
| `by_lemma` | `boolean` | `false` | Искать все формы слова по лемме |
| `limit` | `integer` | `50` | Наибольшее число строк ответа, до 500 |

## Результат { #result }

| Поле | Тип | Описание |
| :--- | :-- | :------- |
| `n_matches` | `integer` | Число вхождений |
| `matches` | `array[object]` | Строки по порядку в тексте: контекст слева `left`, вхождение `keyword`, как оно записано в тексте, и контекст справа `right` |
| `warnings` | `array[string]` | Текст не на русском языке, показаны не все вхождения |
